# Triage labels

技能使用五個標準 triage 角色；本專案直接使用相同的 GitHub label 字串。

| 技能角色 | GitHub label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者尚需評估此 Issue |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人員實作或決策 |
| `wontfix` | `wontfix` | 不會處理 |

技能提及任一 triage 角色時，套用表中的 GitHub label。若專案日後採用既有不同命名，修改中間欄即可。
