## 仍需排程

1. **協作多節點**：改用共享 provider，並建立多副本壓力與故障轉移測試。
2. **外部 Markdown 衝突**：檔案監看、差異比對、三方合併及保留兩份。
3. **資料庫 UX**：Rollup 設定精靈、欄列拖放、欄位刪除回收與更完整的設定驗證。
4. **甘特圖**：關鍵路徑、拖曳時程、資源負載、基線與相依線。
5. **帳號與安全**：密碼重設、邀請信、2FA、SSO、帳號停用與不可竄改稽核。
6. **測試與復原演練**：擴充 API／端對端測試、還原演練、備份異常通知與效能測試。

## 使用原則

- 權限永遠在伺服器端檢查；前端閱讀模式只是一層使用體驗保護。
- 刪除、欄位移除與批次變更前，先確認備份成功並保留可還原路徑。
- 任何要成為測試、飛行或安全決策證據的內容，應在操作前建立版本或匯出並保留來源。
