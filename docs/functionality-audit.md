## 仍需排程

1. **帳號與安全**：密碼重設、邀請信、2FA、SSO、帳號停用與不可竄改稽核。（本輪排除）
2. **產品深化**：公式錯誤僅在檢視中顯示，尚無歷史追蹤；Rollup 為即時計算，尚無背景快取。跨文件同步區塊尚未提供完整 UI；圖片與嵌入內容的 Markdown 匯出只能退化為文字連結。BOM／測試附件尚未提供回收與還原畫面。
3. **工作流深化**：SLA 通知已可自動產生，但尚無管理者可編輯的細粒度通知規則；專案工作日曆目前不會使 scheduler、CPM 或期限計算自動略過假日。
4. **進階整合**：MCP、日曆雙向同步、GitHub 寫入、OAuth 帳號連線與多服務工作流程仍未實作；目前 GitHub 僅唯讀 Issue。
5. **驗證深度**：已可執行 `restore-drill` 與三節點協作壓測；跨可用區故障轉移與完整瀏覽器端對端測試仍需隨實際部署規模建立測試環境。

## 使用原則

- 權限永遠在伺服器端檢查；前端閱讀模式只是一層使用體驗保護。
- 刪除、欄位移除與批次變更前，先確認備份成功並保留可還原路徑。
- CSV 匯入前先匯出或備份資料庫；匯入欄名必須對應既有欄位，且任何列值都以伺服器端驗證結果為準。
- scheduler 必須維持單一邏輯執行者或使用冪等鍵；新增週期任務或通知規則時，不可因服務重啟或重跑造成重複資料。
- 任何要成為測試、飛行或安全決策證據的內容，應在操作前建立版本或匯出並保留來源。
