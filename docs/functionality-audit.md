1. **帳號與安全**：密碼重設、邀請信、2FA、SSO、帳號停用與不可竄改稽核。（本輪排除）
2. **進階整合**：MCP、日曆雙向同步、GitHub 寫入、OAuth 帳號連線與多服務工作流程仍未實作；目前 GitHub 僅唯讀 Issue。

## 使用原則

- 權限永遠在伺服器端檢查；前端閱讀模式只是一層使用體驗保護。
- 刪除、欄位移除與批次變更前，先確認備份成功並保留可還原路徑。
- 任何要成為測試、飛行或安全決策證據的內容，應在操作前建立版本或匯出並保留來源。
